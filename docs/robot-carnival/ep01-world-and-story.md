## 1. 世界の大きな傷（hero-world-building）

**30年前の「白い夜（しろいよる）」——人間がロボットをこわがり、世界中のロボットの記憶を一晩で全部消した。記憶で動くロボットたちはその夜のうちに止まり、夜明けまでだれも手をにぎらなかったので、二度と動かなかった。**

| | 中身 |
|---|---|
| 残っている傷あと | 丘の上に止まったままの巨大ロボット（子どもたちが遊び場にしている）／ロボットをネットにつなぐことを禁じた「つながない法」→ 空に電線とアンテナが1本もない／ジャンク置き場にならぶ、立ったまま止まったロボットたち |
| まだ解決していない問題 | 人と暮らせないロボット（野良ロボット）は、思い出が作れずに少しずつ止まっていく。人間の中には「また消去スイッチを持つべきだ」という声もある |
| 人々の希望 | 年に一度の **記憶祭（メモリー・カーニバル）**。ロボットが思い出を1つ花火にして空にうち上げ、その夜に家族（人）と新しい思い出を作る。**人とロボットが「つながり直す」お祭り** |

## 2. 一行の世界（world-design：現実に入れる嘘は1つだけ）

**もし、ロボットが「人と一緒に作った思い出」を燃やして動いていたら。**

### 3本柱（各2つまで）

| 柱 | 1 | 2 |
|---|---|---|
| 物理 | 海ぞいの坂の町。空が広く、いつも風が吹いている | 空に電線が1本もない（つながない法） |
| 文化 | 人とロボットは「家族」として登録して一緒に暮らす | 記憶祭では、家族のいる者だけが花火をうち上げられる |
| 特殊ルール | 記憶炉（下の表） | — |

### 特殊ルール表：記憶炉（きおくろ）

ロボットの胸にはガラスの炉があり、思い出を燃やして動く。

| 項目 | 中身 |
|---|---|
| できること | 思い出を燃やすと力になる。燃えた思い出は **その景色のまま光になって** 外に見える（花火にもできる） |
| 代償 | 燃やした思い出は、二度ともどらない |
| 前提条件 | 燃えるのは **人と一緒に作った思い出だけ**。ロボットがひとりで記録したものや、コピーした記憶は燃えない |
| 効かない条件 | 炉が空になると止まる。**その夜のうちに人と新しい思い出を作れば、また灯る。夜が明けたら二度と灯らない** |
| 追加の制約 | 燃やした思い出は光になって見えてしまう＝**何を燃やしたか、隠せない** |

> このルールは、第一幕で修理屋のキツネ「ツムギ」がセリフで言う（あとから足さない）。

## 3. 主人公のふつうの1日（ナギ・10歳）

1. 朝、港の汽笛で起きる。となりのベッドにはだれもいない
2. じいちゃんと、だまって焼き魚とおにぎりを食べる
3. 坂を走って学校へ。友だちはみんな、自分の家のロボットといっしょに登校してくる
4. 放課後はじいちゃんのジャンク置き場で、止まったロボットの間を歩く。ロボットに話しかけるのは、じいちゃんに禁止されている
5. 夕方、丘の上の止まった巨人の指に座って、町を見おろす
6. 夜、窓から町を見る。家々の窓には、ロボットの胸の琥珀色の灯りがゆれている。自分の家の窓だけ、暗い

→ この1日で「うちにはロボットがいない」「じいちゃんはロボットをきらっている（理由は言わない）」「町の灯り＝ロボットの胸」が全部見える。

## 8. 話の骨組み（story-structure）

### 借りた構造：昔話『鶴の恩返し』
- ジャンルが遠い（昔話 → SFロボットアニメ）ので、パクリにならない
- 選んだ理由：「助けられた者が、自分の体（羽）を削って恩を返す」「見ないでと言う」という形が、**記憶炉の代償**にぴったり重なる。日本の昔話を土台にすると、海外の審査員にも「日本のアニメ」として届く
- 構造を隠さない：チーム内では「これは鶴の恩返しの構造」と言ってよい

### 構造表（元ネタ → 新作）

| 枠 | 鶴の恩返し | 灯り町 第一話 |
|---|---|---|
| 主人公 | 罠の鶴を助けた若者 | 雨の夜、止まりかけた野良ロボットを助けたナギ |
| 道具・装置 | 自分の羽で織る布 | 自分の思い出で作る「記憶花火」 |
| 敵役（試練） | 「もっと織って」という欲 | 「家族のいる者だけが花火を上げられる」という祭りのならわし、と「家族がほしい」というナギの願い |
| 媒介者 | 布を町で売る商人 | ゲンじい（ロボットの世界から孫を遠ざけながら、ジャンク置き場という「入口」を持っている） |
| 監視者・代償係 | 「見ないで」という約束 | ツムギ（記憶炉のルールを語り、「最近、炉が減りすぎだ」と警告する）＋「作業中は、決して見ないでください」 |

### 捨てたもの
鶴・機織り・雪国・老夫婦・恩返しの金銭・「正体を見られたら去る」という結末。**別れの結末は捨て、「忘れる」に置きかえた。**

### 対立軸（1本）
**思い出を「守る」か、「燃やす」か。**

シーソーが傾く瞬間：
1. 雨の夜、ナギが夜明けまでロクのそばにいて、最初の思い出が生まれる（守る＝作る）
2. ロクが毎晩こっそり、ナギとの思い出を燃やして花火を作る（燃やす）
3. ナギがのぞいて止めようとするが、ロクは燃やしきる（燃やす）
4. 空っぽになったロクに、ナギがもう一度「はじめまして」を言う（作る）

### 反語の一撃
ロク：**「思い出なんて、ただの燃料です。」**

→ 見ている人の中に「いや、思い出こそが全部だ」が立ち上がる。
第二幕の前半で一度（軽く）、第三幕のクライマックスでもう一度（泣きながら）言わせる。

### ログライン
家族のいない少女ナギは、思い出を燃やして動く野良ロボット・ロクを助ける。記憶祭の夜、ロクは「家族の花火」をナギにうち上げるため、ナギとの思い出をすべて燃やそうとしていた。

## 9. 三幕のあらすじ（約5分）

### 第一幕（0:00〜1:20）助ける
- 【つかみ】記憶祭の花火の空。いろんな「思い出の景色」の形の花火。浜辺の家族たち。その後ろで1人で見ているナギ（祭りのしくみを絵だけで見せる）
- 1年後、祭りの前の月。雨の夜。ジャンク置き場で、止まった白い炉のロボットたちの中に、1台だけ炉がチリチリ消えかけているロボット（ロク）
- ナギが修理屋ツムギを呼ぶ。ツムギがルールを言う：「炉が空だ。夜明けまでに、だれかと思い出を作れば灯る。明けたら、もう二度と灯らない」
- ナギはひと晩、ロクの手をにぎって話しつづける。夜明け、2人で朝日を見る。炉に、小さな朝日の光がともる。ロクが目をひらく

### 第二幕（1:20〜3:30）恩返しと代償
- モンタージュ：ナギがロクの右腕を黄色い重機のアームで直す／2人で坂を配達／魚を焼く／丘の巨人の指に並んで座る。炉の中に、その景色が1つずつたまっていく
- ゲンじいは、ロクと目を合わせない（氷山：布をかけた機械）
- ナギ「花火、うち上げられるのは家族のいる子だけなんだ」
- ナギ「思い出、燃やしちゃって平気なの？」 ロク「**思い出なんて、ただの燃料です。**」（1回目）
- ロク「今年は、上げましょう。作っている間は、**決して見ないでください**」
- 毎晩、ガレージのすきまから琥珀色の光。ロクが少しずつおかしくなる：好きなおかずを間違える、ネコの名前が出てこない
- ツムギ「あいつの炉、最近減りすぎだ。何を燃やしてる？」

### 第三幕（3:30〜5:00）見てしまう、そして はじめまして
- 祭りの前夜。ナギはガレージをのぞく
- ロクが炉から思い出を1つずつ取り出して、花火の玉に詰めている。立ちのぼる光は、**全部ナギの顔**。雨の夜、朝日、黄色い腕、焼き魚
- 「やめて！」 ロク「見ないでと、言ったのに」「**思い出なんて、ただの燃料です**」（2回目・声がふるえる）。最後の1つ——はじめての朝日——を詰める
- 祭りの夜。浜辺の列に、ナギとロクが手をつないで並ぶ。筒に火
- 花火がひらく。**夜空いっぱいに、ナギとロクの日々の景色。** 町中の人が見上げる。ゲンじいも見上げる
- ロクの炉は真っ暗。ロクがナギを見て言う：「きれいな子ですね。……あなたは、どなたですか？」
- ロクの体がかたむき、止まりかける（第一幕のルールがここで効く：夜明けまでに思い出を作らないと、二度と灯らない）
- ナギは涙をふいて、手をにぎる。「**はじめまして。わたし、ナギ。**」
- 真っ暗な炉に、ほんの小さな琥珀の火がともる。ロク「……はじめまして」
- ラスト：浜辺を歩いて帰る2人を、うしろからゲンじいが見ている。彼のまがった人差し指のアップ。暗転

## 10. 矛盾チェック

| 問い | 答え |
|---|---|
| なぜ世界はまだ壊れていない？ | 思い出は人と一緒でないと作れない。ロボットは人がいないと生きられず、人はロボットの手がないと町を回せない。おたがいに必要だからバランスがとれている |
| ルールを悪用して儲ける人は？ | 「記憶買い」。お金持ちが、ロボットの古い思い出の光（白い夜より前の景色）を買って見る闇市場がある（シリーズの種。第一話には出さない） |
| なぜナギは今まで普通に暮らせた？ | ロボットを避けるじいちゃんの家で、ロボット抜きで暮らしてきた。町で「ロボットのいない子」は珍しいが、暮らせないわけではない |
| 食べ物はどこから？ | 海ぞいの町なので漁と段々畑。重い仕事はロボット、細かい仕事は人型動物 |
| 一番弱い立場は？ | 人と暮らせない野良ロボット。思い出が作れず、少しずつ止まる。第一話のロクがまさにそれ |
| 設定のうち画面に映るのは？ | 記憶炉・白い夜の傷あと・つながない法（空）・記憶祭・家族登録は全部映る。映らないのは「記憶買い」とゲンじいの過去だけ → **約80%** |

## 11. 弱点チェック

1. **一番退屈になりそうな所**：第二幕のモンタージュ。→ 1カットごとに「炉に景色がたまる」絵を入れて、あとで燃えるものを見せておく（第三幕で全部回収されるので、ここが仕込みになる）
2. **見る人が離れそうな所**：第一幕の「ルールの説明」。→ ツムギのセリフ1行＋炉が消えかける絵だけで見せる。長く説明しない
3. **元ネタが透けて見える所**：「見ないでください」のセリフ。→ 透けてもよい（日本の観客には鶴の恩返しの気配が「予感」になる）。ただし結末は「去る」ではなく「忘れて、また始める」に変えてあるので、パクリではなくアレンジになっている
